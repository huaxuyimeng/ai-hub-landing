安全合规

安全合规：隔离、加密、fail-closed

多租户隔离做成中间件而非人工纪律，密钥密文双存，越权返回 NOT_FOUND。

看隔离设计 看安全规划
aihub.app/cleanup
租户隔离

隔离是中间件，不是纪律

强制注入 tenantId + deletedAt

Prisma 中间件在每次查询自动注入租户与软删除过滤，开发者无需逐处关心。

9 个模型软删除

业务模型统一软删除语义，避免物理删除造成跨租户残留。

越权返回 NOT_FOUND

越权探测返回 NOT_FOUND 而非 FORBIDDEN，不暴露资源是否存在，降低信息泄露。

ts
// Prisma 中间件：强制租户隔离
prisma.$use(async (params, next) => {
  if (params.model && TENANT_MODELS.has(params.model)) {
    params.args.data = { ...params.args.data,
      tenantId, deletedAt: null };
  }
  return next(params);
});
密钥与凭证

明文只出现一次

hash 校验 + 密文双存

Key 采用 hash 校验 + AES-256-GCM 密文双存，原始密钥永不落库明文。

明文仅创建时返回

明文仅在创建接口一次性返回，之后无法再次读取，降低泄露面。

Key 三级解析

租户自配 → 平台 Key 兜底，逐层降级，缺省可用。
