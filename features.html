帕累托前沿算法 = f(能力分, 速度, 混合价)，能力分 ≥ 25 参排，不够格自动排除。

价格走势 + 新闻关联

每日快照记录价格历史；新闻实体自动关联相关模型，动态异动提醒。

算法公式 性价比分 = f(能力) × 速度0.8 ÷ 混合价
混合价 = 0.7 × 输入价 + 0.3 × 输出价
f(x) = { (μ+(x−μ)²)² , x ≥ μ ; (μ−(μ−x)²)² , x < μ }
其中 μ = 55.9（参排模型能力均分），能力分 < 25 不参排，8 个单测覆盖 · 第三方实时榜单（Artificial Analysis）见下方 ↓

辅助模块 2

清理中心：扫描 → 处理 → 报告，三视图分离

重复、空值、孤儿三类问题的统一治理入口，支持智能合并与一键回滚，避免误删造成数据丢失。

  • 扫描视图：重复 / 空值 / 孤儿三类问题清单 + 风险分级
  • 处理视图：智能合并策略 + 人工确认 + 进度实时刷新
  • 报告视图：处理结果统计 + 回滚入口 + 清理历史归档
  • 可逆设计：所有清理操作均带 undoId，30 天内可一键回滚
