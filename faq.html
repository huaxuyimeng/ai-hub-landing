产品定位

毕业设计 MVP，「AI 行业信息聚合与决策辅助」平台；四大核心模块 = AI 新闻聚合 / AI 模型排行 / B 站 UP 主追踪 / AI 早报（PPT 自动生成）。

统一工作台内联动，例如早报会自动引用当日聚合新闻与排行结论，单一模块的结论会沉淀为其他模块的输入。

技术

OpenAI / Anthropic / Gemini / DeepSeek，统一抽象路由，可热切换。

帕累托前沿 + 混合价 + 能力变换，核心算法由单测覆盖（全站 8 个测试文件 130+ 断言）；价格走势来自混合爬虫（内置表 → 官网 → 手动兜底）。

安全

多租户隔离由 Prisma 中间件强制注入 tenantId + deletedAt；密钥 AES-256-GCM 密文双存；越权返回 NOT_FOUND。

租户可自配 Key（AES-256-GCM 密文），平台 Key 兜底；明文仅创建时返回一次。

部署

Vercel 托管 + 7 条 Cron；生产 PostgreSQL、开发 SQLite；R2 + Upstash Redis。

wbi 官方签名 1:1 复刻 + 风控指数退避 + 写保护合并（抓挂不丢旧数据）。

开源 / 贡献

169 份文档可追溯开发全过程；已规划 pnpm Monorepo（apps/web + apps/cron + 11 packages），当前单仓、方案已定。
