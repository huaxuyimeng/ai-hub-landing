核心能力

三件确定的事：可信、可读、可用

让 AI 早报从「每日推送一条标题」升级为「可验证的研究报告」。

A/B/C/D 置信度评级

每条新闻按独立信源数自动判定：A ≥3 源（确证）/ B =2 源（高）/ C =1 源（中）/ D 矛盾（存疑）。评级口径透明，刻意区分「转载数量」与「独立信源数量」。

  • 独立信源计数 · 不重复计算转载
  • 评级口径全页可见 · 不「装权威」
  • 降级版自动标注 · 不静默产出低质内容

11 页三幕叙事 PPT

研究报告式版式：封面 + 概览与方法论 → 两方向索引与详页（AI Coding × 具身智能）→ 验证表 + 趋势 + 信源清单。LLM 失败时自动降级为 Markdown 不静默。

  • 三幕叙事 · 固定骨架 · 页数随条目浮动（10–11 页）
  • LLM 失败 → Markdown 降级 · 不静默
  • 视觉锚点（巨型数字） · 投影友好

生成链路

从触发到 PPT 落盘，6 步可观测

触发方式有两种：每天 07:00 的定时任务，或在页面上手动点一次。两种走的是同一条链路，每一步都有 phase 状态与日志输出，断点续跑由分布式锁 + 幂等性保证。

图注：每个节点都有 phase 状态（collect / select / 2a / 2b / 2c / persist），前端细粒度展示进度。

  1. 01

    触发（定时 / 手动）

    定时：每天北京时间 7:00 由 Vercel Cron 调起（表达式按 UTC 配置），鉴权 Bearer CRON_SECRET，fail-closed 防止裸奔。手动：页面上点一次「立即生成」，走同一入口与同一条链路。

  2. 02

    分布式锁

    withLock('cron:daily-report', 600s) 跨实例互斥，避免多副本同时跑当日报。

  3. 03

    采集候选

    从今日新闻库取最近窗口（默认 8h），按交叉验证规则计算独立信源数；不足 3 条自动放宽到 24h。

  4. 04

    LLM 成稿（v5：3 段并行）

    2a 骨架（封面 / 趋势 / 总览）→ 2b 每条新闻独立并发 → 2c 信源透明块。任一子调用失败 → 局部降级；最多重试 1 次；仍失败 → 纯原文摘要兜底。

  5. 05

    slide-engine 排版 + QA

    11 页三幕叙事：封面 + 概览 → AI Coding 索引与详页 → 具身智能索引与详页 → 验证表 + 趋势 + 信源清单。布局层产出诊断（溢出/缩字号/截断）。

  6. 06

    持久化 + 缓存

    写入 DailyReport 表（content / phase / degraded / pptxBase64 缓存），同时把 PPTX 写 R2。下载时缓存命中即返，未命中即时构建。

页序结构

固定骨架 + 条件页，10–11 页封顶

骨架 6 页恒定，方向页按当日内容出现，传闻页仅在存在待存疑条目时插入——所以页数会浮动，但每页位置可预期。

页页型内容出现条件
P01cover封面：日期 · 主题 · 三条统计 · 置信度分布固定
P02overview本期概览 TL;DR + 置信度评级方法 + 信源家族固定
P03direction-indexAI Coding 方向索引（议题一览 + 置信度角标）有该方向
P04direction-detailAI Coding Hero 议题：巨型数据 + 摘要 + 点评 + 一手链接有 Hero 议题
P05direction-index具身智能方向索引有该方向
P06direction-detail具身智能 Hero 议题有 Hero 议题
P07rumor传闻页：独立信源 vs 转载数对比 + 逐条存疑理由条件插入
P08authorsB 站视频作者状态与一手视频固定
P09verification交叉验证汇总表（议题 / 方向 / 独立信源 / 一手链接 / 置信度）固定
P10trends三条趋势判断（未来一年主线）固定
P11sources信源清单与说明（聚合源 / 视频作者 / 第三方交叉 / 一手官方）固定

骨架 6 页（cover / overview / authors / verification / trends / sources）+ 每方向最多 2 页 + 传闻页（条件）= 10–11 页。2026-09-02 的真实产物为 11 页。
