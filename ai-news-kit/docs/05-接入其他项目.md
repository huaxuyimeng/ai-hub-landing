# 05 · 接入其他项目

> 目标是：**整个目录拷过去就能跑**，不用改任何脚本路径。
> 所有路径都基于 `__dirname` 解析，不依赖当前工作目录。

---

## 一、全量接入（推荐）

### 三步

```bash
# 1. 拷目录（不含 node_modules）
cp -r ai-news-kit/ <目标项目>/tools/ai-news-kit/

# 2. 装依赖
cd <目标项目>/tools/ai-news-kit && npm install        # 只装 pptxgenjs

# 3. 放技能文件（让该项目的 Agent 能加载）
mkdir -p <目标项目>/.workbuddy/skills/ai-news-kit
cp ai-news-kit/SKILL.md <目标项目>/.workbuddy/skills/ai-news-kit/SKILL.md
```

### 改数据源（可选）

编辑 `config/sources.json`：

```jsonc
{
  "sources": [
    { "id": "xxx", "label": "某某源", "url": "https://…/rss", "kind": "generic", "tier": 2, "enabled": true }
  ]
}
```

`kind` 可选：`rss` / `atom` / `generic` / `aibot` / `hn`。
加自定义格式需要去 `aggregate.mjs` 里加一个 `parseXxx` 函数（约 20 行，照抄现有的改）。

**改源前先跑一次看条数，别凭感觉增删。**

## 二、只要数据，不要 PPT

抓取链路**零第三方依赖**（只用 Node 内置 fetch），拷 5 个文件即可：

```bash
mkdir -p myproj/news-fetch/{scripts,config}
cp ai-news-kit/scripts/{aggregate,date-util,storage,time-utils}.mjs myproj/news-fetch/scripts/
cp ai-news-kit/config/sources.json                                   myproj/news-fetch/config/
```

然后：

```bash
cd myproj/news-fetch && node scripts/aggregate.mjs
```

产出 `data/YYYY-MM-DD/news.json`。不需要 `npm install`。

## 三、只要「选稿规范」，不要代码

以下两节可以直接抄进任何项目的 `CLAUDE.md` / `AGENTS.md` / `.cursorrules`：

- [03-置信度评级规则.md](./03-置信度评级规则.md) —— 整份
- [02-每日作业手册.md](./02-每日作业手册.md) —— 「不可违反的纪律」一节

这两块是本项目真正可复用的东西，跟 Node、pptxgenjs 都没关系。

## 四、定时接入

外部 Cron / 平台 Automation：

```bash
# 每天 8:00 抓数据
0 8 * * * node /abs/path/ai-news-kit/scripts/aggregate.mjs
```

> ⚠️ **渲染不要进 cron。**
> 渲染要等 Agent 产出 `brief.json` 之后才跑，由 Agent 触发。
> 否则会渲染出「昨天的选稿 + 今天的日期」这种错位产物。

## 五、作为 npm script 挂进现有项目

在目标项目的 `package.json` 里：

```jsonc
{
  "scripts": {
    "news:fetch":  "node tools/ai-news-kit/scripts/aggregate.mjs",
    "news:pptx":   "node tools/ai-news-kit/scripts/build-pptx.mjs",
    "news:md":     "node tools/ai-news-kit/scripts/brief-to-md.mjs"
  }
}
```

---

## 六、换输出目录 / 换 brief 路径

两个渲染脚本都支持显式参数：

```bash
node scripts/build-pptx.mjs --date 2026-09-14 --out ./dist/reports
node scripts/build-pptx.mjs --brief /path/to/any/brief.json --out ./out
node scripts/brief-to-md.mjs --date 2026-09-14 --out ./dist/日报.md
```

`--brief` 优先于 `--date`，可以用任意路径的选稿文件。

---

## 七、接入后要同步改的地方

| 项 | 位置 | 说明 |
|---|---|---|
| 关注方向 | `SKILL.md` 的 description、`brief.focus` | 默认 AI Coding × 具身智能 |
| 数据源 | `config/sources.json` | 换赛道要换源 |
| 分类关键词 | `config/sources.json` 的 `categoryKeywords` | 换赛道必改 |
| PPT 副标题 | `build-pptx.mjs` 的 `footer()` | 硬编码「侧重 AI Coding × 具身智能」 |
| 免责声明 | `build-pptx.mjs` 末页 | 提到「本期第 5 条」这种要改 |

> 后两项是渲染脚本里**仅有的两处业务文案**，是有意保留的——
> 它们不是「判断」，是版式固定的说明性文字。真要改就改这儿，别到处找。

## 八、验证接入成功

```bash
cd <目标项目>/tools/ai-news-kit
node scripts/aggregate.mjs                              # 应看到 10 源输出
ls data/$(date +%F)/news.json                           # 产物存在
cp templates/brief.template.json data/$(date +%F)/brief.json
node scripts/build-pptx.mjs --date $(date +%F) --out /tmp/t   # 应输出 pptx
```

三步全绿 = 接入完成。
