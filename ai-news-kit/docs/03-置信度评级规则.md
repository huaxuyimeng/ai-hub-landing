# 03 · 置信度评级规则

> 这是本项目唯一站得住的差异点。**规则是硬的，不许凭感觉。**

---

## 一、量表

| 等级 | 名称 | 判定标准 |
|---|---|---|
| **A** | 极高 | ≥3 个**相互独立**的信源，且可追溯到一手官方材料（官网 / 论文 / 公告 / 官方报告） |
| **B** | 高 | 2 个独立信源，或 1 个信源 + 一手官方材料 |
| **C** | 中 | 单一信源；或**多家转载同一家独家** |
| **D** | 存疑 | 关键数字互相矛盾，或全部可溯源到同一原始信源且无官方确认 |

---

## 二、什么是「独立信源」

### 算独立的

- 不同媒体**各自采访**、各自核实后发布的报道
- 一手官方材料（公司公告、论文、监管文件、官方博客）
- 不同语种的独立报道（中文媒体自己采访的 ≠ 英文报道的翻译）

### 不算独立的

- ❌ **转载 / 编译 / 聚合**。A 发了独家，B、C、D 转述 → 只算 1 个
- ❌ 同一家媒体集团的不同栏目（TechCrunch 和它的 newsletter 算 1 个）
- ❌ 都引用同一份通稿（PR Newswire、美通社）
- ❌ 聚合站条目（AITNT、AI工具集、极客公园的每日资讯）——它们是**索引**，不是信源

### 判定方法（三步）

1. 打开报道，找「据…报道」/「援引…」/「sources familiar」这类措辞
2. 如果有，顺着往回找原始出处
3. 所有报道都能追溯到**同一篇** → 只有 1 个独立信源

---

## 三、为什么转载不算（这条规则的价值）

**实测案例 · 2026-09-14 第 5 条**

「Mecka AI 三个月估值从 6000 万冲到近 5 亿美元」

| 层级 | 表象 |
|---|---|
| 聚合层判定 | TechCrunch + Superintelligence News + AI Startups Daily + The AI Beat → **多源**，看起来很硬 |
| 人工核验 | 全部溯源到 TechCrunch 同一篇独家，引述「两位知情人士」 |
| 正确评级 | **C**（不是 A，也不是 B） |

如果直接采信聚合层的 `relatedSources` 计数，这条会被评为 B 甚至 A，
一个**未最终敲定、当事人拒绝置评**的融资传闻就会以「高置信度」的姿态出现在日报里。

### 方向性论证

评级错误在两个方向上的代价是不对称的：

| | 读者行为 | 后果 |
|---|---|---|
| **评级偏低**（实际真，标了 C） | 自己去核实，发现是真的 | 虚惊一场，损失很小 |
| **评级偏高**（实际存疑，标了 A） | 不核实就引用 | 错误结论被传播，**损失不可逆** |

所以：**不确定时往下压一级。宁可多标几个 C。**

---

## 四、明确不做什么

### 不做人工逐条核实

这是**刻意设计，不是偷懒**。

- 真核实一条新闻要：读原文 → 找一手 → 比对数字 → 判断信源可靠性。每天 5 条，代价不可承受。
- 如果宣称「已人工核实」但实际只做了 30%，那就是**伪装成确定性的不确定性**，比不宣称更糟。
- 反过来，「我只数了有几个独立信源在说」是一个**读者可以自己复算的量**。

所以 PPT 第 3 页和最后一页都印着免责声明：

> 置信度只反映「有多少个相互独立的信源在说同一件事」，不反映这件事本身是否为真。

### 不许为了「看起来更可信」放宽

这条规则执行起来会显得评级偏低。这是**特性不是 bug**。

如果某天你想把一条 C 改成 B，先问自己：
「我能指出第二个**自己做过采访**的媒体吗？」
答不出来就别改。

## 五、特殊情形处理

| 情形 | 评级 |
|---|---|
| 有一手官方材料（论文、公告），但只有 1 家媒体报道 | **B**（1 信源 + 一手材料） |
| 有 3 家独立报道，但全是「知情人士」无官方确认 | **B**（不到 A，A 要求可追溯到一手） |
| 公司自吹的 benchmark，无第三方复现 | **B**，且 `why` 里必须写明「出自自家对比表」 |
| 各源数字打架（如估值 4 亿 vs 5 亿） | **D**，且 `conflicts` 写清楚差异 |
| 只有聚合站条目，找不到原始报道 | **不入正条目**，最多进扫读清单 |
|  preprint（arXiv 未同行评审） | 按内容定级，但 `keyFacts` 里标注「预印本」 |

## 六、在产物里怎么体现

评级不是一个隐藏字段，它出现在三个地方：

1. **`brief.json`** → `picks[].lv` + `confidenceScale[]`
2. **PPT 第 3 页** → 整页讲评级规则 + 转载≠独立信源的警示框
3. **每条要闻页右上角** → 彩色角标（A 深蓝 / B 蓝 / C 橙 / D 红）

**规则公开是刻意的**：读者不需要信任我们，他自己就能判断这个评级合不合理。

## 七、自检清单

发布前对每条 pick 问：

- [ ] 我打开过至少 2 个来源的原文吗？
- [ ] 这些来源里，有没有两家其实是转述同一篇？
- [ ] 一手材料（官网/论文/公告）的 URL 填了吗？
- [ ] `sources[]` 里一手来源排在第一位了吗？
- [ ] 有没有哪家数字不一样？写进 `conflicts` 了吗？
- [ ] 如果不确定，我把它往下压了一级吗？
