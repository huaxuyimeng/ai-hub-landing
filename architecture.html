边界怎么钉死

三重强制约束，违规直接阻断合并

边界不靠「约定俗成」，而是让工具在 IDE、Pre-commit 与 CI 三处同时卡住。

包内三层结构

domain（纯逻辑，可独立单测）→ infra（Prisma / HTTP）→ interface（tRPC / React / CLI），只有 index.ts 对外。

exports 锁死入口

package.json#exports 精确声明哪些路径可被 import；import '@aihub/news/src/parsers/wechat-mp' 在 Node 解析期就直接失败。

ESLint 边界规则

各包独立配置 no-restricted-imports，反向依赖与跨包深路径穿透在 IDE 里就报错，写不出来自然也提交不了。

CI 阶段阻断

dependency-cruiser 在 Pre-commit 与 CI 两处校验：循环依赖、db 越界、跨包内部引用一律判 error，阻断 merge。
